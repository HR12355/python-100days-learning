#  PONG Game


##  気付いたこと

- **mainとclassの書き分け**
  「この動作（イベント）が起きたときに、ballをどう動かすか」という順序で組み立てることで、メインの実行ファイル（main.py）と、それぞれの役割を持つクラスファイルの書き分けがクリアになりました。

- **反転（`bounce_y`）**
  ボールが壁に当たって跳ね返る処理のとき、最初は `self.y_move = -10` のように毎回具体的な数字を直接設定しようとしていました。しかし、これだと上に行くときと下に行くときで別々の処理が必要になってしまいます。
  `self.y_move *= -1`で正負逆にすることで、プラスとマイナスが自動で入れ替わり、1行で跳ね返りを表現できることに感動しました。

- **一時停止（`time.sleep`）**
  パドルに衝突するたびに0.6倍し、停止時間を0.6倍することで、ゲームが進むにつれ徐々に加速していくのが面白かった。
