# 🐍 ヘビゲーム（Snake_Game）の開発

PythonのTurtleモジュールを使い、オブジェクト指向（OOP）の考え方を取り入れて作ったヘビゲームです。
単に教材のコードを動かすだけでなく、「コードの裏側で何が起きているのか」の仕組みを自分なりに納得できるまで掘り下げて実装しました。

## 🚀 開発環境・使用技術
- Python 3.14
- Turtleモジュール（画面描画・キー操作イベント）
- timeモジュール（ゲームスピードの制御）

## ✨ 開発で意識したこと・学んだこと

### 1. クラスでの整理と `__init__` のイメージ
クラスの設計について、最初は頭の中で繋がりにくかったのですが、`snake = Snake()` と呼び出した瞬間に、裏で自動的に `__init__`（初期化）の処理がすべて適用されてヘビが誕生する、という具体的なイメージが自分の中でカチッと噛み合いました。
また、`self.head = self.segments[0]` のように、誰が見ても「これはヘビの先頭（頭）のことだな」と一目でわかるような、丁寧で迷わない命名を意識して設計しました。

### 2. 画面をスムーズに動かす仕組み
ヘビが動くときのアニメーションがチラつかないよう、以下の描画制御を組み合わせました。
- `screen.tracer(0)` で自動描画を一度ストップ。
- バックグラウンドで裏絵を完成させてから、`screen.update()` で一気に画面に表示。
- そのままだと処理が速すぎるため、`time.sleep(0.1)` を挟んでプログラムを0.1秒ずつ休憩させ、人間がプレイしやすい速度を保つ。

この一連の組み合わせによって、ゲームが滑らかに動く仕組みを学びました。

### 3. アルゴリズムの工夫（逆順のループ処理）
ヘビの体がちぎれずに連動して動くロジックを作る際、`range(start, stop, step)` を活用しました。
後ろの体が一つ前の体の位置を順番に追いかけていくように、インデックスを後ろから前へと逆順に回すループ処理（ステップ機能）を工夫して実装しています。

### 4. 定数管理による「変更に強いコード」
プログラム内で使う数値（ヘビの速度や設定値など）は、ファイルの上部にすべて大文字（ALL CAPS）で定数として定義しました。
こうしておくことで、後から「ゲームの難易度を変えたい」と思ったときも、下のメインロジックを1行も触ることなく、一番上の数値を1箇所書き換えるだけで安全に修正できるメリットを実感しました。
