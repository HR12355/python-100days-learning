# Snake Game (ヘビゲーム)

PythonのTurtleモジュールを使用した、シンプルなヘビゲームです。
オブジェクト指向を意識し、クラスを活用して可読性の高いコードを目指して実装しました。

## 開発環境 / 使用技術
- Python 3.14
- Turtle (画面描画・イベント制御)
- time (ゲームスピードの制御)

## 特徴・実装したこと

### 1. クラスによる設計の整理
- `snake = Snake()` のように、インスタンス生成時に `__init__` が適用される仕組みを意識して実装。
- `self.head = self.segments[0]` のように、コードを読んで直感的に構造が理解できる命名。
- 繰り返し行う処理はメソッドとして分離。

### 2. アルゴリズム
- ヘビの体が連動して動くロジックにおいて、`range(start, stop, step)` を使用。
- 後ろのセグメントが前方のセグメントの位置を逆順（後ろから前へ）で追いかけるループ処理を実装。

### 3. 定数管理
- 速度や初期設定などの数値は、ファイル上部に大文字（ALL CAPS）の定数として定義。
- 後からの数値変更やメンテナンスが容易な設計。
