# Snake Game

Python講座の中で、オブジェクト指向（OOP）を学ぶために作成したヘビゲームです。

## 「分かったこと・苦労したこと」

- **クラス（__init__）のイメージ**
  `snake = Snake()` と呼び出した瞬間に、裏で自動的に初期設定である属性を付与するイメージ。
- **クラスの継承**
  `super().`で`turtle`の機能をそのまま使えるようになる。
- **外部ファイルへの「書き込み、読み込み」**
  `with open`でテキストファイルのデータの書き込み、読み込み。
- **定数**
  速度などを一番上に大文字で書いておくと、下のコードを一切触らずに変更できて便利。
- **ヘビの体の移動**
  3体のブロックでスタートするヘビの体が、ちぎれずに動く仕組みを実装。
  後ろから順番に動かすことで、滑らかに見えるように。
